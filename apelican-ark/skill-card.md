# 方舟

换电脑时，不想把 AI 从头设置一遍，就用方舟。

它会把 Codex 和 WorkBuddy 里你自己装的技能、调好的设置、留下的记忆和自动化，收进一份本地备份。到了新电脑，先让你看清会改什么，确认后再恢复。

## 什么时候会用到

- 准备换电脑或重装系统，怕漏掉平时用顺手的 AI 设置。
- 折腾出一套好用的技能和自动化，想先留个存档。
- 已经有一份方舟备份，想安全地放回新设备。

## 三种备份有什么区别

- **基础备份**：身份、技能、设置、记忆和自动化；不含会话和敏感配置。
- **中等备份**：在基础备份上，再加入连接器与项目索引；仍不含会话和敏感配置。
- **全量备份**：在中等备份上，再加入本地能找到的会话文件与索引；敏感配置仍要单独确认。

需要时，可以把所选范围内的用户自管敏感配置另外放进 AES 加密包。账号登录文件、Cookie 和设备绑定授权始终不备份。

## 它不会偷偷动文件

- 先把准备备份或恢复的内容列出来。
- 只有你明确确认后才开始写入。
- 新电脑遇到同名文件时，先留一份原文件，不会直接删掉。
- 做完再按清单检查，告诉你哪些成功、哪些还要重新登录。

## 使用前知道这些

- 需要 Python 3.10 或更高版本。
- 账号登录无法随备份保持有效；换机后按新设备流程重新登录。
- 加密包可以用同一口令恢复配置文件，但这不代表账号授权仍然有效。
- 受客户端索引、版本和服务端数据限制，全量备份可能只能保留记忆，旧聊天不一定能在客户端完整显示。

## 它需要哪些权限

- 只读取你选择范围内的 `~/.codex` 和 `~/.workbuddy` 文件。
- 只在你明确确认后，写入指定备份位置或新设备对应目录。
- 不读取浏览器 Cookie，不读取账号登录文件，不联网，也不上传任何备份内容。
- 恢复遇到同名文件时，先把新设备原文件移到 `~/.ark/restore-conflicts/`，不会删除本地多出的文件。
