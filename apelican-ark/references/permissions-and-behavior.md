# 权限与行为说明

方舟只在本机读取和写入文件，不联网，不上传备份内容，也不操作小红书账号。

## 读取范围

| 用户选择 | 读取范围 | 为什么需要 |
| --- | --- | --- |
| 基础备份 | `~/.codex` 与 `~/.workbuddy` 中的身份、技能、设置、记忆和自动化白名单 | 生成最小可用的迁移备份 |
| 中等备份 | 基础范围，加连接器配置与项目索引 | 保留更多工具接入和项目线索 |
| 全量备份 | 中等范围，加本地能找到的会话文件与索引 | 尽力保存本地会话材料；不保证客户端显示 |
| 可选敏感配置 | 仅限所选范围内的用户自管配置值 | 用户单独确认后写入 AES 加密包，以便用同一口令恢复 |

任何级别都不读取或备份浏览器 Cookie、账号登录文件、系统钥匙串、DPAPI/设备绑定数据和云端 OAuth 会话。

## 写入范围

- 备份预览不写任何文件。
- 用户确认备份后，只写入用户指定位置或默认的 `~/ark-backups/`。
- 恢复预览不写目标目录，也不修改备份包。
- 用户确认恢复后，只写入目标用户的 `~/.codex`、`~/.workbuddy` 和用于报告、冲突保护的 `~/.ark`。
- 遇到同名文件时，先把目标设备原文件移到 `~/.ark/restore-conflicts/`；不删除目标设备多出的文件。

## 代码会执行什么

- `ark_backup.py`：扫描所选本地目录，生成清单、备份和校验信息。
- `ark_restore.py`：读取清单，先展示变化；确认后恢复并生成报告。
- `ark_verify.py`：校验备份，并调用同包的 `ark_restore.py` 做只读预演；不会调用网络程序或上传工具。
- `ark_selfcheck.py`：检查 Python、包内脚本和本机是否存在 Codex/WorkBuddy 目录。

## 依赖

- 普通备份只需要 Python 3.10 或更高版本。
- 只有用户主动选择 AES 加密敏感配置包时才需要 `pyzipper>=0.3.6`。
- 缺少依赖或口令时直接停止，不改用未加密 ZIP。

## 明确做不到

- 不迁移账号登录状态，也不保证旧设备登录文件在新设备有效。
- 不保证旧聊天在客户端列表中完整显示；受版本、索引和服务端数据限制，可能只能继续使用已恢复的记忆。
- 不直接写 WorkBuddy 数据库恢复自动化；只生成计划，再通过产品当前提供的官方接口执行并回读。
- 不自动发布、评论、私信或运营任何小红书账号。
