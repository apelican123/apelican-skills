# 踩坑记录

这些是公开版整理时保留或纠正过的真实限制，不是理论清单。

## 1. 密钥不在开放平台

用微信开放平台注册「移动应用 / 网站应用」拿到的 AppID，不是公众号 AppID。草稿接口会报凭证错误。当前正确入口是微信开发者平台 → 我的业务 → 公众号 → 基础信息 / 开发密钥。

旧博客写「公众平台 → 开发 → 基本配置」已经过时。官方把开发接口管理迁到了开发者平台。

## 2. AppSecret 只出现一次

平台不回显密钥。启用或重置后必须立刻写入本地 `.env`。忘记了只能重置，旧值作废。

## 3. 个人号先实名，企业号先认证

启用 AppSecret 时，个人主体缺管理员实名、非个人主体缺微信认证，都会被弹窗拦住。这不是脚本 bug。

## 4. 运营者看不到开发密钥

必须是管理员或已绑定开发者。运营者登录开发者平台，业务数量可能是 0。

## 5. 白名单要的是公网出口，不是 127.0.0.1

`127.0.0.1` 是本机回环。微信服务器看到的是你的公网 IPv4。开代理时，查 IP 的出口和真正请求 `api.weixin.qq.com` 的出口必须是同一个。

## 6. title 和 cover 都要写

wenyan 文档写过「正文有图可省略 cover」。实际缺 cover 会报「未能找到文章封面」。公开版按实测要求两字段都填。

## 7. 封面比例不是 1080×864

早期脚本提示 1080×864，那不是公众号图文列表封面。当前图文封面按 **2.35:1** 准备，常用 900×383；分享小图是 1:1。重要文字放中央，避免被裁掉。

## 8. 外链图片会被丢掉

草稿 `content` 里的图片 URL 必须来自微信「上传图文消息内的图片」接口。wenyan 会代传；自己贴外站图，进草稿后可能变空白。

## 9. 标题 32 字、摘要 120 字、作者 16 字

这是 `draft/add` 的字段限制。超过会被拒或截断。分享简介不要靠截正文开头，能写 `digest` 就写。

## 10. 创建草稿后不要盲着重试

HTTP 超时或终端没看到成功提示时，先数草稿箱。连续重试会留下多篇重复草稿。发表、群发、删除都要另外的明确授权；本技能不做。

## 11. 家用 IP 会变

宽带拨号或切换 Wi-Fi 后白名单失效。现象还是 40164。把新 IP 加上，或改用固定 IP 的 wenyan server 模式。

## 12. 不要在对话里回显密钥

公开版脚本只报告「已加载 / 未加载」，不打印任何凭据片段。

## 13. 封面不要手搓纯色交差

用户明确要求封面和配图走生图模型。纯色 PIL 块、随机几何、把完整标题印在图上，都会被看成敷衍。没有生图时用 `templates/cover-fallback.html` 做成一张词 + 大留白的平面卡，不要发明第三种更丑的退路。

## 14. 配图不是证据

AI 图和 HTML 卡只能当气氛或讲解。图注必须写「配图」。假新闻现场、假聊天截图、假论文页面会把文章证伪。

## 15. 油画光和二次元大眼

廉价 AI 常见：体积光、厚涂、蜡像脸、大眼动漫。出现就重做。平面海报风动漫只有用户点名才用。

## 16. 小白被命令行吓跑

用户说不会推文时，先走 beginner.md。一次只让人在网页上点一件事。PowerShell 默认可能禁止运行 `.ps1`，要用 Bypass，或由 AI 跑 bash。

## 17. 「发布成功」被理解成粉丝已经收到

wenyan 打印的「发布成功」= 草稿创建成功。必须同时告诉用户去后台预览，并说明发表和群发的差别。

## 18. 小红书技能上传识别不了

上传页截图点名的是 `.md` `.txt` `.html` `.css` `.js` `.py` `.json` `.xml`。`.sh` `.ps1` `.env` `.gitignore` 以及无扩展名的 `LICENSE` 可能被忽略。1.3 公开包把脚本写进 `references/scripts.md`，环境变量模板写进 `references/env-example.md`。功能仍是 `wenyan publish` 进草稿箱。
