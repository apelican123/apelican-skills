# 小白怎么把第一篇推出去

这份给两种人：

- 你有公众号，但不知道后台点哪里
- 你把这个技能丢给 AI，自己不会敲命令

AI 读到「不会发 / 小白 / 帮我推文」时，**先跟这份走**，不要一上来丢 `npm` 和 `wenyan`。

## 先把三个词说人话

| 词 | 意思 |
| --- | --- |
| 草稿箱 | 文章已经在你的公众号后台里了，**粉丝还看不见** |
| 发表 | 文章出现在公众号主页 / 历史消息，不一定弹到粉丝聊天列表 |
| 群发 | 推到粉丝的订阅号消息里，通常有次数限制 |

本技能只负责把排好的稿子放进**草稿箱**。发表和群发必须你自己在网页上点。这是故意的，避免 AI 误发给所有粉丝。

Markdown = 一种带标题的纯文本。你不会写也没关系，把文章发给 AI，让它按模板改。

## 你只需要做的事

1. 电脑打开 https://mp.weixin.qq.com/ ，微信扫码，确认能进自己的公众号。
2. 把这个技能文件夹交给 AI（或告诉它文件夹路径）。
3. 对 AI 说下面这句：

> 我是小白。我有公众号，不会推文。这是我的文章（或我还没写）。请按这个技能一步一步教我：先拿 AppID 和密钥，再排版进草稿箱。命令你来跑。不要自动群发。

4. AI 每做完一步，应该告诉你「现在请你去网页上点什么」，而不是一次甩十行命令。
5. 草稿出现后，按 [mp-publish.md](mp-publish.md) 自己预览、再发表。

## AI 必须遵守的带法

1. 先问：公众号有没有、文章在哪、电脑是 Windows 还是 Mac。缺一样补一样。
2. 带用户去 **微信开发者平台** 拿 AppID / AppSecret / IP 白名单。禁止带去开放平台注册移动应用。启用密钥前，让用户先打开记事本，密钥只出现一次。
3. Node.js、wenyan、`.env` 由 AI 在用户电脑上检查和安装；用户不会终端就不要让用户复制一长串。
4. 封面先生图。用户听不懂 900×383 时，AI 自己生成并保存到文章旁边。
5. 进草稿箱成功后，用口语告诉用户：现在粉丝还看不见。然后打开 [mp-publish.md](mp-publish.md) 带他点预览和发表。
6. 任何一步失败，只解释当前这一步，不要把整份故障手册贴出去。

## 你可能卡死的地方

- 登录开发者平台后看不到公众号：你不是管理员。回 https://mp.weixin.qq.com/ 看账号角色。
- 启用密钥提示没实名：先在公众平台完成管理员实名，再回来。
- 记事本保存成 `环境变量.txt` 或 `.env.txt`：文件名必须正好是 `.env`。
- PowerShell 提示无法运行脚本：见故障排查里的 Bypass 写法，或让 AI 改用 bash。
- 草稿箱里找不到：看 [mp-publish.md](mp-publish.md)，菜单名可能是「内容与互动」。
