# 公众号草稿箱排版

写好 Markdown 以后，按人文、科技或社会热点三种版式排好，并生成简约封面和配图，保存到微信公众号草稿箱。最后仍要你自己在后台点发表。

## 什么时候会用到

- 文章已经写完，只差公众号能看的排版。
- 不想再把稿子手工贴进 135 编辑器。
- 第一次给公众号接开发接口，不知道 AppID、密钥和 IP 白名单点哪里。
- 有公众号，但不知道草稿箱在哪、发表和群发有什么区别。

## 它能帮你做什么

- 按页面逐步找到公众号 AppID、AppSecret，并把电脑的公网 IP 加进白名单。
- 按文风生成简约封面和正文配图；没有生图模型时，用平面 HTML 卡片代替。
- 提供三套港式阅读节奏的模板：人文纸墨、科技青简、社会热点港闻。
- 只创建草稿，方便你预览后再决定发不发。

## 使用前知道这些

- 你需要一个自己的微信公众号（订阅号或服务号），并且是管理员或开发者。
- 本机要安装 Node.js，再安装开源命令行工具 `wenyan-cli`。
- 个人主体账号先完成管理员实名，才能启用 AppSecret。
- 它不会自动群发，也不会替你点「发表」。
- 不要去微信开放平台建「移动应用」来拿密钥，那不是公众号的 AppID。

## 可以这样说

「我是小白。我有公众号，不会推文。这是我的文章。请按技能一步一步教我，命令你来跑，不要自动群发。」
