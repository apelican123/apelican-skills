# 视频转 Markdown

看完网课、访谈或吐槽视频，不想把整段口播再听一遍。丢一条链接，整理成能直接存进笔记的 Markdown。

也覆盖大家常搜的说法：视频总结、视频笔记、文字笔记、转文字、视频转写、B站字幕、YouTube 转录。

## 什么时候会用到

- 刚看完一条 B 站或 YouTube，想留一份能检索的笔记。
- 网课太长，先要一份带时间戳的大纲。
- 访谈、讲座只有视频，没有文稿。
- 想把视频写进 Obsidian，而不是停在收藏夹里。

## 它怎么做

1. 先查这条视频有没有官方字幕或 AI 字幕。有就只抽字幕，不下载画面。
2. 没有字幕，才下载音轨（不下载整部视频），用必剪云端识别；你要求不上传时，改用本地 Whisper。
3. 清洗重复行和语气词，按主题分章，写成 Markdown 文件落到磁盘。

## 使用前知道这些

- 需要 Python 3.10+ 和 yt-dlp。没有字幕时还要 ffmpeg。
- 必剪不是官方稳定接口，等于把音频传到 B 站。内部会议、未公开内容不要走它。
- 不帮你破解大会员、付费墙或 DRM。
- 语音识别会写错人名和黑话，摘要能用，当引文要自己核对。

## 可以这样说

「把这个视频整理成笔记，只要 Markdown。」
「完整转写，不要摘要。」
「用本地识别，不要上传。」
