# 草稿进后台之后，怎么让粉丝看到

技能把文章放进草稿箱以后，**粉丝还看不见**。下面在电脑浏览器里做。菜单名字偶尔会改，找不到就在左侧找带「内容」「图文」「草稿」的入口。

官方后台：https://mp.weixin.qq.com/

## 1. 找到那篇草稿

1. 微信扫码登录公众号。
2. 左侧常见路径（按你页面上实际有的点）：
   - **内容与互动 → 草稿箱**，或
   - **内容与互动 → 图文**，或
   - 首页右侧「近期编辑」
3. 用标题搜索。本技能创建的草稿，标题就是 Markdown 里 `title:` 那一行。
4. 点标题打开。

如果完全没有这篇：接口可能失败了。不要再点一次发布脚本。先看对话里有没有「Media ID」或报错，再查故障排查。

## 2. 先预览到自己的微信

打开草稿后找 **预览**。填自己的微信号，发到手机上看：

- 标题会不会被裁切
- 封面小图能不能认出主体
- 正文在手机上段间距、图片、错字

预览不是发表。只有你自己看得到。

## 3. 再决定「发表」还是「群发」

这两个不是一回事。点错了影响粉丝，所以技能不代点。

| 按钮（页面用词可能略有不同） | 粉丝会怎样 | 适合 |
| --- | --- | --- |
| **发表** / 发布 | 文章出现在公众号主页、历史消息；不一定弹到聊天列表 | 先上架、不占群发次数 |
| **群发** | 推到粉丝的订阅号消息 | 你真的要推这一期 |

个人订阅号的群发次数有限。拿不准就先 **发表**，不要群发。

群发前后台通常还要选标签 / 全部粉丝，并再次确认。那一页出现「发送」之前都可以返回。

## 4. 发表之后草稿会消失

按官方规则：草稿被发表或群发后，会从草稿箱拿走。这是正常的，不是被删库。

## 5. 手机备选

电脑不在时，可用微信「订阅号助手」看草稿、预览、发表。排版仍建议在电脑上用本技能做完再上车。

## AI 到这一步该说什么

不要说「已经发布成功」。要说：

> 草稿已经在后台了。你现在去 mp.weixin.qq.com 打开它，先预览到自己微信。看起来没问题再点发表。群发你没点头我不会让脚本去做。
