# 标题和作者

保存草稿前，必须先有 `title` 和 `author`。能从用户稿子里认出来的就填，认不准就问，不要编。

## 识别顺序

按这个顺序取，取到就停：

### 标题 `title`

1. Markdown 顶部 YAML 里已有 `title:`，且不是占位（「标题」「未命名」「你的标题」）。
2. 正文第一个一级标题 `# ...`（不要把 `##` 当成标题）。
3. 用户在对话里明确说「标题是……」。
4. 以上都没有：只问一句「这篇标题用哪句？」，等用户回再写进 YAML。

标题写成不超过 32 个汉字。超过就请用户改短，不要擅自删到看不懂。

### 作者 `author`

1. YAML 里已有 `author:`，且不是占位（「你的名字」「作者」）。
2. 文末或文首出现 `作者：` / `撰稿：` / `文 /` 后面的名字。
3. 用户在对话里报了自己的公众号署名。
4. 以上都没有：问「作者栏写谁？」，等用户回。不要用「佚名」，也不要用技能作者名顶上。

作者不超过 16 个字。

## 写回 YAML

识别或确认之后，把值写进稿件顶部：

```markdown
---
title: 识别到的标题
cover: ./cover.jpg
author: 识别到的作者
digest: 可选
---
```

原来没有 YAML 就补这一段；原来有就只改空着的字段，不覆盖用户已经写好的非占位内容。

## 不要做的事

- 不要用文件名当标题（除非用户说文件名就是标题）。
- 不要用第一段正文截 32 字当标题。
- 不要把校对、编辑、公号名误认成作者。
- 不要在用户没点头时，用 AI 起一个「更好看」的标题去覆盖原标题。
